# FUTURE_DS_02 – Customer Retention & Churn Analysis

## Project Overview
This project focuses on analyzing customer churn and retention patterns using a telecom customer dataset.

The objective of this analysis is to identify:
- Why customers leave the platform
- Customer segments with higher churn risk
- Retention trends and customer lifetime behavior
- Business strategies to improve customer retention

---

## Dataset Used
Telco Customer Churn Dataset

---

## Tools Used
- Excel
- Data Analytics
- Customer Retention Analysis
- Business Intelligence

---

## Key Analysis Performed
- Churn Rate Analysis
- Retention Trend Analysis
- Customer Lifetime Analysis
- Contract Type Analysis
- Payment Method Analysis
- Internet Service Analysis

---

## Key Insights
- Customers with month-to-month contracts showed higher churn rates.
- Long-term customers were more likely to stay with the company.
- Fiber optic users experienced comparatively higher churn.
- Customers using electronic check payments had increased churn behavior.

---

## Business Recommendations
- Promote long-term subscription plans with discounts and loyalty rewards.
- Improve customer support for high-risk customer groups.
- Launch personalized retention campaigns.
- Review pricing and service quality strategies.
